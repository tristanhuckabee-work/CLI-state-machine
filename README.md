# CLI-state-machine
A CLI Package that creates a state machine for a Simulation of digital forensics.
Written in both Python and Powershell Script.

## Python Script
To run the python script
- Clone the repo.
- Ensure python and pip are installed.
- Run the following:
```bash
cd python/
pip install .
```
[!TIP] You can uninstall with `pip uninstall statmach-py`
